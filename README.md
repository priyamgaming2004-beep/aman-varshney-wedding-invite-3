# Aman & Janvi — Wedding Invitation

A static, mobile-first cinematic wedding invitation built with plain HTML, CSS and JavaScript.

## Deploy on GitHub Pages

1. Create/open a GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. Ensure `index.html` is at the repository root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save. GitHub will give you a `github.io` URL.

## Background music

For copyright/safety reasons, no commercial music is bundled.

To add your own licensed/owned track:
- Put an MP3 at `assets/music/wedding-song.mp3`
- Keep the filename exactly `wedding-song.mp3`
- The Open Invitation button will attempt to start it, and the floating ♪ button can pause/play it.
